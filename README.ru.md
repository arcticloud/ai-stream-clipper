# AI Stream Clipper: нарезка стримов в вертикальные клипы

[English version](README.md)

Даёшь ссылку на запись стрима, получаешь до 3 готовых вертикальных клипов: сверху лицо стримера, снизу
игра, хук-заголовок, субтитры по словам и текст поста с хештегами для Shorts, TikTok, Reels и X.
Работает на Windows и Mac, со стримами на русском и английском. Ключи API не нужны: моменты выбирает
сам Claude Code, всё остальное считается на твоём компьютере бесплатно.

## Что нужно

- Claude Code (подписка Claude от $20 в месяц).
- Windows 10/11 или Mac. Python 3.9+ ([python.org](https://www.python.org/downloads/), при установке на
  Windows поставь галочку «Add Python to PATH»).
- Видеокарта NVIDIA ускоряет расшифровку в 5–10 раз, но и без неё всё работает, просто дольше.
- 5 ГБ свободного места.

## Установка (один раз)

1. Положи эту папку в папку скиллов Claude под именем `ai-stream-clipper`:
   - Windows: `%USERPROFILE%\.claude\skills\ai-stream-clipper\`
   - Mac: `~/.claude/skills/ai-stream-clipper/`

   Через git: `git clone https://github.com/arcticloud/ai-stream-clipper $HOME/.claude/skills/ai-stream-clipper`
   (или скачай ZIP с GitHub и распакуй туда же).
2. Открой Claude Code в любой папке и напиши: **настрой клиппер**
3. Claude сам проверит компьютер, поставит что нужно (ffmpeg, yt-dlp, расшифровку речи) и напишет
   READY, когда всё готово. Первый раз это займёт 5–15 минут: качается модель расшифровки.

## Как пользоваться

- **нарежь этот стрим https://www.youtube.com/watch?v=...** (подходят YouTube, Twitch, Kick или файл
  с компьютера)

Один стрим за раз, из него до 3 клипов. Стрим на 4 часа на компьютере с RTX 3060 занимает примерно
10–15 минут от ссылки до готовых клипов. Без видеокарты NVIDIA расшифровка идёт дольше.
Готовые клипы лежат в папке `StreamClipper` в твоей домашней папке: видео `.mp4`, текст поста `post.md`
и отчёт `report.md`.

YouTube пишет «подтвердите, что вы не робот» (бывает после многих скачиваний) или стрим 18+?
Зайди в YouTube в Firefox и скажи Claude: «используй куки из firefox».

## Бесплатно без подписки (Ollama)

Можно запустить Claude Code на бесплатной локальной модели: поставь [Ollama](https://ollama.com),
скачай модель под свою память (16 ГБ: Qwen 3.5 9B, 32 ГБ и больше: Qwen 3.5 27B), в терминале набери
`ollama launch claude` и дальше те же команды. Моменты она выбирает хуже Claude и медленнее.

## Важно

Нарезай только тех стримеров, которые разрешают клипы (у многих есть свои программы для клипперов),
и пересматривай каждый клип перед публикацией.
